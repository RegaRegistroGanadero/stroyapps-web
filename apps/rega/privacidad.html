Política de privacidad

Última actualización: 10 de septiembre de 2026

Resumen: la información ganadera registrada en REGA se guarda localmente en el dispositivo. StroyApps no recibe automáticamente fichas de animales, fotografías, aretes, historiales, información sanitaria ni respaldos creados por el usuario.

1. Responsable de la aplicación

REGA es una aplicación de control ganadero desarrollada por StroyApps.

Para dudas relacionadas con esta Política de Privacidad o con el funcionamiento de REGA, puedes comunicarte mediante el correo: soporte.rega@gmail.com.

2. Información almacenada por REGA

REGA permite al usuario registrar y administrar información relacionada con su actividad ganadera. Dependiendo de las funciones utilizadas, esta información puede incluir:

  • Datos del productor y del rancho.
  • Datos de animales, como arete, nombre, sexo, raza y fecha de nacimiento.
  • Fotografías de animales y de elementos relacionados con el registro ganadero.
  • Genealogía, incluyendo información de padre y madre cuando el usuario la registra.
  • Historial de cambios y estados del animal.
  • Información de vacunación, desparasitación, tratamientos y jornadas sanitarias.
  • Información sobre venta, fallecimiento, extravío u otros eventos registrados por el usuario.
  • Fierros o marcas ganaderas que el usuario decida almacenar.

Esta información se almacena localmente en el dispositivo del usuario mediante la base de datos de la aplicación.

3. REGA no envía automáticamente los datos ganaderos a StroyApps

REGA está diseñada para funcionar principalmente de forma local. StroyApps no mantiene un servidor destinado a recibir automáticamente las fichas de animales, fotografías, historiales ganaderos, información sanitaria o respaldos del usuario.

La información ganadera puede salir del dispositivo únicamente cuando el propio usuario realiza voluntariamente una acción como exportar información, crear o compartir un respaldo, compartir la ficha de un animal o enviar un archivo mediante otra aplicación.

4. Fotografías y acceso a la cámara

REGA puede solicitar permiso para utilizar la cámara con el objetivo de permitir al usuario tomar fotografías para sus registros.

El acceso a la cámara se utiliza únicamente cuando una función de la aplicación lo requiere y el usuario decide utilizarla. Las imágenes tomadas para REGA se almacenan como parte de los datos locales de la aplicación y no son enviadas automáticamente a StroyApps.

5. Notificaciones y recordatorios

REGA puede solicitar permiso para mostrar notificaciones. Estas notificaciones pueden utilizarse para recordatorios relacionados con actividades o eventos registrados dentro de la aplicación, como seguimiento sanitario.

REGA también puede detectar el reinicio del dispositivo o cambios relevantes del sistema para volver a programar recordatorios locales. Esta función no implica que los datos ganaderos sean enviados a un servidor de StroyApps.

6. Respaldos y transferencia de información

REGA permite crear respaldos manuales con extensión .rega. Estos archivos pueden contener la información necesaria para restaurar los datos de la aplicación, incluyendo registros ganaderos y archivos asociados.

Los respaldos se crean únicamente cuando el usuario solicita esta acción y quedan bajo su control. El usuario decide dónde guardarlos, copiarlos o compartirlos.

REGA desactiva el sistema de copia automática de datos de Android para evitar restauraciones parciales o no controladas de la información interna de la aplicación.

Los respaldos pueden incluir un identificador técnico generado por REGA para reconocer la instalación de origen. Este identificador se utiliza para aplicar correctamente las reglas de restauración y los límites de funciones asociados al dispositivo. No está diseñado para identificar personalmente al usuario.

7. Publicidad y servicios de Google

La versión gratuita de REGA puede mostrar publicidad y utilizar anuncios recompensados para ofrecer determinadas funciones o ampliar límites dentro de la aplicación.

Para ofrecer publicidad, REGA utiliza el Google Mobile Ads SDK (Google AdMob). Este servicio puede recopilar o procesar automáticamente determinados datos técnicos, entre ellos:

  • Dirección IP, que puede utilizarse para estimar una ubicación general.
  • Interacciones con la aplicación y con los anuncios.
  • Información de diagnóstico y rendimiento.
  • Identificadores del dispositivo o identificadores relacionados con publicidad.

Google puede utilizar estos datos para publicidad, medición, analítica, seguridad y prevención de fraude, de acuerdo con sus propias políticas y configuraciones.

REGA también utiliza Google User Messaging Platform (UMP) para gestionar, cuando corresponda, mensajes y opciones de consentimiento relacionadas con privacidad y publicidad.

Puedes consultar más información en las políticas de Google:

  • Política de Privacidad de Google
  • Cómo utiliza Google la información para publicidad

8. Conexión a Internet

Aunque las funciones principales de control ganadero de REGA están diseñadas para trabajar localmente, la aplicación puede utilizar conexión a Internet para funciones que dependen de servicios externos, especialmente publicidad, gestión de consentimiento y acciones que el usuario decida realizar mediante aplicaciones o servicios externos.

9. Soporte por correo electrónico y WhatsApp

REGA permite al usuario iniciar voluntariamente una comunicación con soporte mediante correo electrónico o WhatsApp.

Para facilitar el diagnóstico de un error, REGA puede preparar un mensaje que incluya información técnica como la versión de REGA, fabricante y modelo del dispositivo, versión de Android y versión del SDK de Android.

El usuario puede revisar o modificar el mensaje antes de enviarlo. REGA no adjunta automáticamente la base de datos ganadera ni las fotografías de los animales.

Cuando el usuario decide enviar un mensaje, la información enviada también queda sujeta a las políticas del servicio de correo, WhatsApp o de la aplicación utilizada para realizar la comunicación.

10. Exportaciones y archivos compartidos

Algunas funciones de REGA permiten generar archivos, exportar registros o compartir información. Estas acciones son iniciadas voluntariamente por el usuario.

Una vez que un archivo es exportado o compartido fuera del espacio privado de REGA, su almacenamiento, transmisión o tratamiento puede depender de la aplicación, servicio o ubicación elegida por el usuario.

11. Seguridad de la información

StroyApps busca reducir la exposición innecesaria de los datos ganaderos manteniendo la información principal de REGA en el dispositivo del usuario y evitando su transmisión automática a servidores propios.

No obstante, ningún dispositivo, sistema de almacenamiento o método de transmisión puede garantizar seguridad absoluta. Se recomienda proteger el teléfono con un método de bloqueo seguro y conservar los respaldos .rega en ubicaciones confiables.

12. Conservación y eliminación de datos

Como los datos principales de REGA se almacenan localmente, el usuario mantiene el control directo sobre ellos mediante las funciones disponibles en la aplicación.

El usuario puede eliminar registros desde REGA y, cuando corresponda, eliminarlos definitivamente desde la papelera. La desinstalación de la aplicación o el borrado de sus datos desde Android puede eliminar la información local que no haya sido respaldada previamente.

StroyApps no puede recuperar datos locales eliminados del dispositivo si el usuario no conserva un respaldo.

13. Menores de edad

REGA es una herramienta de gestión ganadera y no está diseñada específicamente para niños. StroyApps no busca recopilar intencionalmente información personal de menores mediante las funciones principales de la aplicación.

14. Servicios y aplicaciones de terceros

REGA puede abrir o interactuar con servicios externos cuando el usuario solicita compartir información, enviar un reporte, abrir WhatsApp, utilizar una aplicación de correo u otras acciones similares.

StroyApps no controla las prácticas de privacidad de esos servicios externos. Se recomienda revisar las políticas de privacidad correspondientes antes de proporcionarles información.

15. Cambios a esta Política de Privacidad

Esta Política de Privacidad puede actualizarse cuando se incorporen nuevas funciones, cambien los servicios de terceros utilizados por REGA o sea necesario reflejar cambios técnicos, legales o de distribución.

La fecha de la versión más reciente se mostrará al inicio de esta página.
